### Outbox/queue — transactional outbox + worker dispatcher (P2, ADR-002 accepted + executed)
- **ADR-002 written + accepted**: Postgres `outbox_events` is the durability source of truth; API appends INSIDE the business transaction (`OutboxService.append(client, …)` takes the caller's `withTenant` client — commit publishes, rollback erases, no write-then-publish dual writes); worker dispatches via per-batch `FOR UPDATE SKIP LOCKED` transactions (crash → rollback → re-claim; at-least-once; no stuck `processing` states, no reaper job); retries `min(base·2^(n−1), cap) + jitter`; DLQ = `state='dead'` (loud, alert-ready, operator recovery); handlers idempotent keyed on event id; unhandled types stay pending for other workers (registry-partitioned stream); **Redis/BullMQ deferred behind the outbox** (TECH_STACK_EVALUATION recommended path — Postgres alone runs the queue at P2 volume)
- **Migration `006_outbox`** (dev + test DB, DATABASE_DESIGN §5): `outbox_events(id, tenant_id, type, schema_version, payload_ref, correlation_id, state, attempts, next_attempt_at, created_at, published_at)` — state CHECK (`pending/published/dead`), **global partial claim index** `(next_attempt_at) WHERE state='pending'` (cross-tenant drain is the design — documented exception to tenant-leading indexes), tenant diagnostics index; RLS tenant policy (same fail-closed `NULLIF` shape) + **`REVOKE UPDATE, DELETE … FROM aicsp_app`** (API role append-only)
- **Worker `OutboxDispatcher`** (apps/worker, `pg` dependency added): claim→handle→finalize in one transaction; claims only registered types; exponential backoff + jitter + DLQ; poll loop with overlapping-tick backpressure; connects as the **owner role** via new **`WORKER_DATABASE_URL`** (cross-tenant claims would be blocked by RLS — ADR-003 two-role model; worker exits at startup naming the variable when missing); `start` script loads the repo-root `.env` via `node --env-file-if-exists`
- **Env contract**: `WORKER_DATABASE_URL` / `WORKER_POLL_MS` / `TEST_WORKER_DATABASE_URL` (ENVIRONMENT_VARIABLES + `.env.example`); turbo.json `test.env` extended — strict env-mode silently dropped the new test var until declared (observed: integration suite skipped)
- **Tests ×17 (Gate B)**: API side as the app role — **atomicity proof (rolled-back append disappears)**, cross-tenant isolation + WITH CHECK forge, append-only enforcement, no-scope fail-closed; worker side as the owner role — publish with envelope round-trip, retry→backoff→DLQ chain, **SKIP LOCKED exactly-once claims under two concurrent dispatchers**, unhandled types untouched, cross-tenant drain, re-claim after finalize loss; unit — backoff math, empty-registry no-op, claim-filter surface, poll loop
